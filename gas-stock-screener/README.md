# 台股巴菲特篩選機器人（Google Apps Script 版）

完全免費，部署在 Google Sheets 上，自動篩選台股被低估的優質標的。

## 功能特色

- **零成本部署**：Google Apps Script 免費運行
- **Google Sheets 儀表板**：條件格式自動上色，一目瞭然
- **自動排程**：每週一、三、五盤後 18:00 自動執行
- **LINE / Gmail 通知**：篩選完畢立即推播
- **批次模式**：可掃描全市場（突破 6 分鐘限制）

## 部署步驟

### 1. 建立試算表

1. 至 [Google Sheets](https://sheets.google.com) 新建試算表
2. 命名為「台股巴菲特篩選機器人」

### 2. 建立 Apps Script 專案

1. 試算表選單 →「擴充功能」→「Apps Script」
2. 將下列檔案逐一貼入（每個檔案對應一個 .gs 檔）：

| 檔案 | 說明 |
|------|------|
| `Config.gs` | 篩選條件、Token 設定 |
| `DataFetcher.gs` | FinMind / TWSE API 呼叫 |
| `Screener.gs` | 巴菲特 7 指標評分邏輯 |
| `SheetManager.gs` | 工作表初始化與結果寫入 |
| `Notifier.gs` | LINE / Gmail 通知 |
| `Main.gs` | 主程式、排程、選單 |

3. 儲存專案

### 3. 填入設定

**方法 A（推薦）** — Script Properties（更安全）：
```
專案設定 → 指令碼屬性 → 新增：
  FINMIND_TOKEN    = 你的 FinMind Token
  LINE_NOTIFY_TOKEN = 你的 LINE Token
```

**方法 B** — 直接填入 `Config.gs`：
```javascript
FINMIND_TOKEN:    'your_token_here',
LINE_NOTIFY_TOKEN:'your_line_token',
```

### 4. 初始化

1. 在編輯器選擇函式 `initializeSheets` → 執行
2. 授權請求 → 允許（需要讀寫 Sheets、發送 Email、外部 URL）

### 5. 執行篩選

**方式一**：GAS 編輯器中執行 `runScreener()`

**方式二**：回到試算表 → 選單「📊 股票篩選機器人」→「🚀 立即執行篩選」

**方式三**：設定自動排程 → 選單「⏰ 設定自動排程」

## 工作表說明

| 工作表 | 說明 |
|--------|------|
| `篩選結果` | 自動更新的篩選排名，依總分排序 |
| `自選清單` | 在 A 欄填入想追蹤的股票代號（4–5 碼） |
| `執行日誌` | 每次執行記錄，保留最近 200 筆 |

## 篩選指標

| 指標 | 條件 | 權重 |
|------|------|------|
| ROE 股東權益報酬率 | > 15%（3年均） | 25% |
| EPS 成長率 | 連續3年正成長 | 20% |
| 負債比率 | < 50% | 15% |
| 本益比 P/E | < 20 | 15% |
| 股價淨值比 P/B | < 3.0 | 10% |
| 自由現金流 FCF | > 0 | 10% |
| 股利殖利率 | > 0% | 5% |

**總分 ≥ 60 分**通過篩選（可在 Config.gs 調整）

## 結果顏色說明

| 顏色 | 分數 | 意義 |
|------|------|------|
| 🟢 深綠 | ≥ 80 | 優質標的 |
| 🟡 淺綠 | 70–79 | 良好標的 |
| 🟡 黃色 | 60–69 | 可關注 |

## GAS 執行限制說明

| 限制 | 免費帳號 |
|------|----------|
| 單次執行上限 | 6 分鐘 |
| 每日執行上限 | 90 分鐘 |
| API 呼叫間隔 | 建議 0.7 秒 |

**自選清單模式**：一次最多 ~50 檔，約 2–5 分鐘完成。

**全市場批次模式**：執行 `startBatchScreening()`，每 10 分鐘自動執行一批（30 檔），全部完成後發送通知。
